# Takt — 02 Stack Brand Kit

**Version:** 0.1 · **Date:** 16 October 2026

The selected production direction is **02 Stack**: three staggered horizontal bars, cyan-to-green color direction, dark navy default. The waveform and hybrid are not production logos.

Start with [the visual gallery](preview/index.html), [the PNG overview](preview/takt-stack-brand-preview.png), or [the brand guide](style/brand-guide.md).

## Contents

| Folder | Contents |
|---|---|
| `svg/` | Transparent scalable marks, horizontal/stacked lockups, wordmarks, tagline signatures |
| `png/` | Matching transparent PNG exports at normal and 2× resolution |
| `icons/` | Five tile styles, nine PNG sizes from 16 to 1024 px, SVG masters, ICO favicon, monochrome pinned-tab input |
| `banners/` | Dark/light documentation banners in SVG and 1×/2× PNG |
| `style/` | Brand guide, design tokens, CSS theme, offline documentation template, README snippet, contrast report |
| `preview/` | Offline gallery and contact-sheet overview |
| `source/` | Mark geometry and asset inventory; SVG masters themselves are editable source |
| `reference/` | Actual original generated boards and a crop of selected Concept 02 |

## Production note

The SVG kit is a clean reconstruction of the approved raster direction, not a claim that original vector source files existed. Wordmarks are outlined and do not require fonts. No font binaries are distributed. The original boards remain available for comparison and provenance; unselected concepts in those boards are archival only.

The offline HTML previews need only a browser. Keep their relative folder structure intact. The CSS is a documentation starter, not a prebuilt Docusaurus/MkDocs theme package. Logos and banners can be used independently of the HTML.
