# Original references — not all production options

`01-original-exploration-board.png` contains the original six concepts. The selected concept is **02 Modern / Stack**, not 01 Waveform, the clock, or the stylized letter T.

`02-waveform-and-stack-exploration-board.png` contains the two shortlisted directions. The **right-hand Stack panel** is the selected direction. `selected-02-stack-reference.png` is a crop of that panel.

`03-rejected-hybrid-reference.png` records the later hybrid exploration. It was not selected and must not be substituted for the Stack logo.

These files are copies of the actual supplied raster boards. Production vector reconstructions are in the sibling `svg/`, `icons/`, and `banners/` folders. They deliberately standardize geometry and typography rather than claiming to recover nonexistent original vectors.
