One workflow, explicit limits.

Keep independent checks in one group. Let the scheduler admit eligible work, or choose a smaller job budget.

takt run checks --jobs 2 --cpu 2 --memory 4GiB

Use --enforcement required only when the run must refuse to start without the requested protection.
