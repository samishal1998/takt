## One binary. Your existing commands.

Install on Linux x86-64 or macOS Apple Silicon, then use the tools already in your project.

```sh title="Install Takt"
curl -fsSL https://github.com/samishal1998/takt/releases/latest/download/install.sh | sh
```

```sh title="Run your workflow"
takt run checks
takt plan checks --output json
```

Prefer a project-local command? The [Takt wrapper](/takt/installation/#project-wrapper)
downloads, verifies, and caches its pinned release by default. Set
`TAKT_USE_SYSTEM=1` to opt into reusing an installed Takt from your PATH.
